# Adopt a Buddy design system

The visual idea is **the neighbourhood storybook**: real animals are introduced with honest photography while illustrated guides carry the emotional journey from first hello to ordinary life at home.

The product remains an adoption marketplace. Artwork creates attention and warmth; it never hides pet facts, actions, errors, or ownership boundaries.

## Files

- `system.md` defines tokens, composition, typography, and interface patterns.
- `motion.md` defines the animation language and accessibility fallbacks.
- `assets.md` records asset roles, generation prompts, licensing, and delivery rules.
- `.21st/design.json` is the machine-readable project context for future 21st work.

## Non-negotiable experience rules

1. "Meet the buddies" stays visible in the primary navigation.
2. Actual pet listings use uploaded photographs and real API values.
3. Generated art is decorative editorial illustration and never implies a real adoption record.
4. Every animated scene has a complete static state.
5. Sound starts off, loads only after interaction, and never carries essential meaning.
